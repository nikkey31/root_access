# Root Access

**Root Access** — детективно-триллерная игра в жанре симулятора ноутбука серийного маньяка, разработанная на движке **Godot 4 (GDScript)** в рамках курса ТРПО.

## Суть игры
Игрок получает доступ к ноутбуку серийного маньяка в стиле классической ОС (Windows 98). Чтобы выяснить правду и выйти на одну из нескольких концовок, нужно исследовать виртуальную файловую систему, искать подсказки на фотографиях (включая метаданные и дату съёмки), читать заметки и использовать консольные команды в терминале для расшифровки скрытых данных.

## Стек технологий
- **Движок:** Godot 4.x
- **Язык:** GDScript
- **Данные сюжета и VFS:** JSON (`res://data/`)
- **Контроль версий и планирование:** Git, GitHub (Issues, Pull Requests, Kanban Projects)
