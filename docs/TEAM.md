## Правила работы с Git
1. Основная стабильная ветка — `main`, рабочая интеграционная ветка — `dev`.
2. Каждая задача выполняется в отдельной ветке от `dev` (`docs/...`, `feat/...`, `fix/...`, `content/...`).
3. Слияние в `dev` — только через Pull Request после проверки тимлидом.
4. Коммиты делаются регулярно в дни разработки с понятным описанием (`feat:`, `docs:`, `fix:`, `content:`).
